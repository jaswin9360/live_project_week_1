# Telco Customer Churn — Simple Project

A beginner-friendly Python project for Week 1 and Week 2: data acquisition, data cleaning, EDA, and a simple browser dashboard.

## Run on macOS

Open Terminal and move into this folder:

```bash
cd path/to/telco_churn_simple_project
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python week1_setup.py
python week2_eda.py
python -m streamlit run app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`. Open it in your browser.

## Important

- Keep the original CSV in `data/raw/`.
- The cleaned CSV and graphs are generated by `week2_eda.py`.
- The `TotalCharges` fallback rule is a project-specific estimate, not a universal rule.
- This project covers Week 1 and Week 2. Model training is a later step.


## Compare any two columns

Open the **Column Analysis** page in the Streamlit sidebar and choose two different columns.

- **Numeric + numeric:** shows Pearson correlation and a scatter plot.
- **Numeric + category:** shows count, mean, median, minimum, and maximum for each group, plus a bar chart.
- **Category + category:** shows a cross-tabulation of counts and row percentages, plus a bar chart.
- You can inspect sample rows and download the selected two-column comparison as a CSV.

Correlation and group differences show associations; they do not prove that one column causes changes in the other.
